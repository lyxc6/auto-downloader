# 自动下载器改进计划

## 目标
1. 创建树形图生成脚本，展示完整的目录结构
2. 改进下载脚本，修复问题并添加新功能

## 分析结果

### 网站结构
- 文件管理器页面：https://www.flyingfry.cc/index.php/224.html
- 总目录数：30个（分布在3页上）
- 目录层级：多层嵌套结构
- 文件类型：图片、视频、文档、压缩包等

### 现有问题
1. parse_items() 函数会错误解析导航链接（如"首页"、"全部"等）
2. 没有处理分页（当前只处理第一页）
3. 没有进度显示
4. 没有错误处理和重试机制
5. 没有命令行参数支持

## 实施计划

### 任务1：创建树形图生成脚本（tree_view.py）

**功能：**
- 递归遍历所有目录
- 收集所有文件夹和文件名
- 以树形图的形式输出到控制台和文件
- 处理分页
- 显示统计信息

**实现步骤：**
1. 复用现有的session和get_page_content()函数
2. 改进parse_items()函数，正确解析目录和文件
3. 实现递归遍历函数，收集目录树数据
4. 实现树形图输出函数
5. 处理分页逻辑
6. 添加统计信息

**输出格式：**
```
📁 根目录
├── 📁 github_backup
│   ├── 📁 2022
│   │   ├── 📁 04
│   │   │   ├── 📄 102791572.png
│   │   │   ├── 📄 1219809599.png
│   │   │   └── ...
│   │   └── ...
│   └── ...
├── 📁 papers
│   └── ...
└── ...

统计信息：
- 总目录数：XXX
- 总文件数：XXX
- 文件类型分布：...
```

### 任务2：改进下载脚本（downloader.py）

**改进点：**

1. **修复parse_items()函数**
   - 排除导航链接（检查href是否包含网站域名）
   - 只解析真正的文件和目录

2. **处理分页**
   - 实现分页逻辑，遍历所有页面
   - 已有get_total_pages()函数，需要集成到crawl_directory()中

3. **添加进度显示**
   - 显示当前进度（已下载/总文件数）
   - 显示下载速度
   - 显示已用时间和预计剩余时间

4. **添加错误处理和重试机制**
   - 捕获网络异常
   - 自动重试（最多3次）
   - 记录失败的文件

5. **支持断点续传**
   - 跳过已存在的文件（已有）
   - 记录下载进度

6. **添加命令行参数**
   - `--url`：指定目标URL
   - `--dir`：指定下载目录
   - `--tree`：只显示目录树，不下载
   - `--retry`：指定重试次数
   - `--verbose`：显示详细信息

**实现步骤：**
1. 修复parse_items()函数
2. 集成分页处理
3. 添加进度显示类
4. 添加错误处理和重试机制
5. 添加命令行参数解析
6. 重构代码结构

## 风险和注意事项

1. 网站可能有反爬虫机制，需要控制请求频率
2. 文件数量可能很多，需要考虑内存使用
3. 网络可能不稳定，需要有重试机制
4. 部分文件可能很大，需要考虑磁盘空间
